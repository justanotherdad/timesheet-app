# CTG Timesheet Site – Job Aid

The job aid now lives **in the application** as the **Site Guide**, so there is a single copy to
keep current. Open it from the **book icon** in the header of any page, or from the **menu (☰) →
Site Guide**.

The content is maintained in [`components/GuideModal.tsx`](components/GuideModal.tsx). Edit that file
when site behavior changes; do not reintroduce a second copy here, since the standalone markdown
version drifted out of date against the live site.

The guide covers:

1. Getting Started
2. Dashboard Overview
3. Timesheets
4. Approvals
5. Manage Users
6. Organization & Timesheet Options (including Delegation and how site access is determined)
7. Budget Detail
8. Bid Sheets
9. Reports
10. View Timesheet Data & Export
11. Holiday & Pay Calendar
12. Timesheet Confirmations
13. Need Help?

For developer-facing documentation, see [`WORKFLOW.md`](WORKFLOW.md), [`README.md`](README.md), and
[`Access Levels.md`](<Access Levels.md>).
